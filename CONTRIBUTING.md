# Contributing to Linevale

Thanks for your interest. The project is at an early design stage, so the most useful contributions right now are design feedback, rule corrections, and bug reports once a playable build exists.

## Issues

- Search existing issues before opening a new one.
- Use issues for concrete, actionable items: unclear rules, UX problems, balance concerns, or bugs with reproduction steps.
- For open-ended design discussion, use GitHub Discussions if it is enabled for the repository.
- Include the build version, browser or operating system, and the relevant save file when reporting a bug. Remove any personal information from saves before attaching them.
- English and Chinese are both fine.

## Pull requests

- Keep pull requests small and focused: one concern per pull request.
- Describe what changes and why, and link the related issue.
- Match the existing code style. Do not reformat unrelated code in the same change.
- New dependencies need a short justification in the pull request.
- Add or update tests when behavior changes. Make sure the build and checks pass.
- By submitting code, you agree that it is licensed under the MIT License (inbound = outbound).
- Do not include creative assets in a pull request. See below.

## Assets are not open to external submissions

The project does not accept contributed artwork, audio, map data, fonts, or other creative assets. Every asset needs clear, documented provenance, and mixing externally supplied files makes that hard to verify. All shipped assets are created for this project or come from a documented CC0/OFL source.

If you want to suggest a CC0/OFL resource, open an issue with the source URL and license instead of a pull request. Accepted third-party assets will be recorded in `CREDITS.md`.

## Scope

The MVP scope is defined in the design document under `2026-11-03/game-design/outputs/`. Please discuss scope changes in an issue before implementing them.

## Conduct

Keep discussions civil and focused on the project. Disagreement is fine; personal attacks, harassment, and discriminatory language are not.
