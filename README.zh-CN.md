线城（Linevale）是一款非商业的浏览器地铁线路规划游戏。你要在小型抽象城市中铺设彩色线路、调度列车、把乘客送到对应类型的目的地、每周选择一次升级，并让整个网络尽可能久地运转下去，直到它最终堵塞。

## 玩法（计划中）

核心循环：**铺线 → 调车 → 送客 → 每周选升级 → 撑到网络崩盘。**

- **线路。** 用彩色线路连接站点。一条线至少连接 2 个站，列车双向运行并在端点折返；设计上限为 6 条线。
- **乘客。** 站点形状代表目的地类型：居住、工作、商业、休闲。乘客只需到达任意一个同类型站点，而不是某个指定站点。只有被多条线路共同经过的站点才能换乘；线路在空白处交叉不产生换乘。
- **施工时间，而非货币。** 改线消耗的是施工时间，不是金钱，也没有需要刷取的资源经济。
- **每周暂停。** 一周为 7 个游戏日（1× 速度下 140 秒）。每周结束时游戏暂停，预览一个新站点，并给出 2–3 张升级卡，玩家选择 1 张。升级方向包括新增列车、加挂车厢、扩充站台容量、解锁新线路、全网提速、枢纽改造和超载宽限。
- **失败。** 若某站的排队人数超过容量并持续足够久（标准图 18 秒，不同地图为 15–24 秒），本局结束。MVP 中这是唯一的失败条件，也没有胜利条件：游戏是无尽生存模式，最佳周数保存在本机。
- **地图。** 计划提供 3 张手工地图：潮汐湾（入门）、棋盘旧城（标准）、三河岛（挑战），初始 6–8 个站点，逐步扩展到 14–17 个。

## 操作方式（计划中）

鼠标与触控都是主要输入方式，最终按键绑定可能在实现时调整。

| 操作 | 鼠标 | 触控 |
|---|---|---|
| 选择线路 | 点击线路 chip | 点按线路 chip |
| 新建或延伸线路 | 从端点拖到目标站点 | 长按端点，再拖动 |
| 移除端点 | 把端点拖到空白处 | 拖到空白处，或使用“移除端点”按钮 |
| 删除线路 | 选中线路后删除（需二次确认） | 同上 |
| 指派列车 | 把列车 token 拖到线路 chip | 先点 token，再点线路 chip |
| 站点信息 | 悬停 | 点按站点 |
| 暂停 / 变速 | `Space`、`1`、`2`、`4` | 界面按钮 |
| 取消 | `Esc` 或右键 | “取消”按钮 |

## 存档（计划中）

存档以本地优先设计，并强调可迁移：

- 3 个本地存档槽位，保存在浏览器中；游戏自动存档。
- 任意时刻都可以把当前进度导出为单个 JSON 文件，并在另一台设备或另一个浏览器中导入。
- Web 版与桌面版共用同一套存档 Schema（v1）。
- 无账号、无服务器、无云同步。导入时会校验格式，并在覆盖前备份原有槽位。

可迁移的进度是有意的设计目标：不注册账号也能把一局游戏带到另一台机器上。

## 路线图

### 计划中 — Web MVP

- 完整核心循环、3 张手工地图、4 种站点、6 条线路、7 类升级。
- 同一构建同时支持鼠标与触控。
- 潮汐湾前两周的上下文教程提示。
- 3 个本地存档槽位，以及 JSON 导出/导入。
- 可用于浏览器托管的静态 Web 构建。

### 后续 — Windows 桌面版

- 使用 Tauri 2（当前倾向，尚未最终确定）封装同一套 Web 构建，打包为 Windows 安装包。

### 后续 — MVP 之后的候选内容

尚未承诺，也不属于 MVP：

- 环线与线路中段插站。
- 每张地图的通关目标与奖牌。
- 用于无尽模式或每日挑战的程序化地图。

### MVP 明确不做

账号、云同步、排行榜、联机、无尽模式、每日挑战、地图编辑器、轮渡、桥梁费用、成就与付费内容。
